# Project Planning

The project was planned and executed in a structured manner to ensure timely completion and effective implementation of all modules.

## 📌 Phase 1: Requirement Analysis
- Identified the problem of price comparison across multiple e-commerce platforms  
- Analyzed user needs such as quick comparison and image-based search  
- Defined project objectives and scope  

## 🧠 Phase 2: Research and Feasibility Study
- Studied existing systems and their limitations  
- Researched web scraping techniques and machine learning models  
- Selected suitable technologies such as MobileNet, OpenCV, and Flask  

## 🏗️ Phase 3: System Design
- Designed overall system architecture  
- Planned modules such as:
  - Web Scraping Module  
  - Image Processing Module  
  - Machine Learning Module  
  - User Interface  

## 💻 Phase 4: Implementation
- Developed web scraping scripts for Amazon and Flipkart  
- Integrated MobileNet model for image classification  
- Built backend using Flask  
- Designed frontend using HTML, CSS, and JavaScript  

## ⚙️ Phase 5: Testing
- Tested individual modules (unit testing)  
- Performed integration testing  
- Verified accuracy of predictions and correctness of scraped data  

## 🚀 Phase 6: Deployment
- Integrated all modules into a complete system  
- Deployed the application for user access  
- Ensured smooth functioning and performance  

## 📊 Phase 7: Evaluation
- Analyzed system performance and accuracy  
- Identified improvements and future enhancements  

---

The structured planning approach ensured that the project was completed efficiently, with all functionalities working as expected.
